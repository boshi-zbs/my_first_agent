# 🤖 AI 测试效能平台 (AI QA Agent)

这是一个基于大模型、Playwright 和 RAG 技术构建的**企业级 AI 测试辅助系统**。它不仅能够对复杂需求进行智能拆解，还能利用历史知识库进行风险预警，最终一键导出符合企业规范的 Excel 测试用例，并具备**直接接管浏览器执行 UI 自动化操作**的能力。

## ✨ 核心功能

- **🧠 需求智能拆解与澄清**：基于 LLM 分析需求文档（支持 PDF/Word/Excel/飞书链接），自动提取“明确需求点”、“模糊遗漏点（待产品确认）”和“隐含业务规则”。
- **📚 企业级长期记忆 (RAG)**：使用 ChromaDB 和本地嵌入模型，将历史需求和用例存入向量数据库。在分析新需求时，自动联想历史经验（如：历史由于没做验证码校验导致过Bug），实现“越用越聪明”。
- **📊 并发用例生成与 Excel 导出**：采用“分治法”并发架构，自动拆分长需求，突破大模型单次输出字数限制，一键合并导出包含标准“八要素”的 Excel 测试用例表。
- **🚀 动态探索式 UI 自动化**：
  - 提取测试用例中的 URL，使用无头浏览器静默探索真实页面元素。
  - 自动生成抗变更的 Playwright 定位代码，并拉起浏览器真实执行。
  - 自动截图并在网页端回显结果。
